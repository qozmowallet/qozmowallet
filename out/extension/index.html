A FEW SIMPLE STEPS

Make yourself
at home.

This release is a downloadable ZIP. Installation uses Chrome’s Developer mode; it is not yet listed in the Chrome Web Store.

  1. 01

    Download and extract.

    Download the ZIP above, then extract it. Keep the qozmo-wallet-extension folder in a permanent location.

  2. 02

    Open Chrome extensions.

    Enter chrome://extensions in Chrome’s address bar. Enable Developer mode at the top right.

  3. 03

    Load Qozmo.

    Click Load unpacked and select the extracted qozmo-wallet-extension folder containing manifest.json.

  4. 04

    Pin it. Open your space.

    Open Chrome’s extensions menu, pin Qozmo, then click its icon to open Qozmo Quantum. Qozmo opens beside the page you are browsing. Create or import an account, unlock, receive and review test transfers inside the panel.

A separate local vault.

The extension stores encrypted wallets in its own browser storage. It does not automatically access the wallet you created on the website.

Native SOL and BTC derive separate addresses from the standard EVM vault. Quantum has a separate recovery phrase and signing archive. Imported Quantum accounts remain read-only.

Know your connections.

Network access supports configured blockchain RPCs, Solana Devnet, the Bitcoin Signet indexer, explorers, Kraken markets, and DefiLlama metrics. The sidePanel permission displays the wallet beside your browser. A custom HTTPS bundler asks for access to its specific server when you connect.

The Quantum side panel includes Assets, Activity and Keys. Import ERC-20 contracts, find tokens at your address, and choose which assets to show. Send, Receive and Security stay close by. It does not inject a provider into websites or connect to dapps. Quantum transfers require your compatible Robinhood Testnet ERC-4337 bundler.

Keep a backup close.

Export an encrypted backup before removing the extension, deleting Chrome profile data, or updating it. For updates, replace the files in the same folder and select Reload in Chrome.

Quantum WOTS stays on Robinhood Testnet. SOL uses standard Ed25519 and BTC uses standard SegWit ECDSA. Native mainnet signing and lost-device Quantum spending recovery are not enabled.
