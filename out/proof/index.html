04 · $QZO & ADOPTION

Usage is a metric.
Value capture needs a mechanism.

The current wallet pays network gas in ETH. The landing page lists the $QZO token on Robinhood Chain mainnet. Protocol fee sharing, buybacks, burns, and staking rewards are not integrated into this wallet.

Before making a value-capture claim

  • Identify the canonical token contract and chain.
  • Define an optional paid service and its fee source.
  • Specify allocation, permissions and accounting onchain.
  • Review security, governance and legal requirements.
  • Publish deployed contracts and measurable usage.

This is a specification checklist, not an approved tokenomics model.

Qozmo Quantum is currently a testnet prototype. A successful WOTS-core reference transaction is https://explorer.testnet.chain.robinhood.com/tx/0xc24e471f61c604bf48032ff734a2c967f0c8ec14dd0be675eec12339e818a376. It predates the Qozmo integration, so we do not present it as a Qozmo-originated transaction. Reproducible checks are available in our Proof & Status page.

Our configured source repository is https://github.com/imrybrndo/qozmo-wallet; public access has not yet been established. We will share it as a public repo once it is accessible without authentication.

We have not announced a Qozmo mainnet launch date. Mainnet release requires reproducible testnet evidence, public reviewed source, independent security review, a reviewed stateful-key/recovery policy, and chain-specific operational checks.

The current wallet pays network gas in ETH. $QZO already has a configured token contract on Robinhood Chain mainnet, separate from the Quantum testnet account. No wallet-linked $QZO fee share, buyback, burn, or staking reward mechanism is implemented. Wallet adoption does not automatically create tokenholder cash flow. Token utility and economics will need a separate, explicit specification before we claim value capture.
